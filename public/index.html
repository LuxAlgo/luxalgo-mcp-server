Build with Vela’s open-source core

The chart at the top of this page, like the one in your chat, is drawn by Vela’s open-source core: the charting library behind Vela, with its own WebGL2 renderer, drawing tools and keyless exchange providers. Put it in your own app from velacharts.dev.

Pair it with this server: library_get_source_code hands your agent an indicator’s Pine Script® source, and Vela’s open-source core runs it on a chart through PineTS (how).

  • velacharts.dev
  • Vela’s open-source core on GitHub
  • @luxalgo/vela on npm

Run this server locally

The npm package runs the same tools over stdio. Locally it can also read your own brokerage accounts, read-only, with keys that stay on your computer (setup).

Run with npx
npx -y @luxalgo/mcp
